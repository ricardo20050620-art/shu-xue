# 考研数学二全面练习大题库

> 覆盖考研数学二大纲全部 11 章、57 小节，2105 道精选题，逐题配详细解析、重点提示与方法总结。纯前端实现，打开即用，数据本地保存。


## 快速开始

### 方式一：单文件版（推荐，最简单）

直接双击打开 `index-single.html` 即可使用，无需解压、无需安装任何东西。所有CSS、JS和题目数据都已内联到这一个文件中。

### 方式二：多文件版

1. 将整个文件夹放到任意位置
2. 双击打开 `index.html`
3. 确保 `index.html` 与 `css/`、`js/` 文件夹在同一目录下

> **注意**：不要在ZIP压缩包预览窗口中直接打开文件，那样会导致关联的CSS/JS文件无法加载，页面显示空白。请先解压再打开。

## 功能特性

### 七大模块



| 模块       | 说明                          |
| -------- | --------------------------- |
| **章节目录** | 全部 11 章可展开，显示每小节题目数与完成进度    |

* 显示 / 隐藏答案切换

* 全文搜索（关键词、考点、编号）

## 技术栈



* **纯前端**：原生 HTML + CSS + JavaScript，无构建工具，无后端依赖

* **数据与 UI 分离**：题目数据按章节拆分为独立 JS 文件（`js/data/ch01.js` – `ch11.js`）

* **状态持久化**：localStorage 保存学习进度、错题、收藏、设置

* **数学排版**：HTML + CSS 实现分数、根号、矩阵、上下标等数学公式

* **响应式布局**：CSS Flex / Grid，适配桌面与移动端

## 使用方法

### 本地运行

直接用浏览器打开 `index.html` 即可使用，无需任何服务器或安装。



```
双击 index.html → 浏览器打开 → 开始练习
```

### 推荐浏览器



* Chrome / Edge（推荐）

* Firefox

* Safari

### 数据保存

所有学习记录（答题进度、错题、收藏、设置）保存在浏览器 localStorage 中：



* 同一浏览器同一设备：数据自动保留

* 清除浏览器数据：记录会被清空

* 换设备 / 换浏览器：数据不共享（纯前端特性）

## 扩展指南

### 添加新题目



1. 打开对应章节的数据文件（如 `js/data/ch03.js`）

2. 找到对应小节的 `questions` 数组

3. 按以下格式添加题目对象：



```
{
  id: '3.2-041',           // 编号：章节.小节-序号
  difficulty: '基础',        // 基础 | 提高 | 难题 | 真题
  type: '选择',             // 选择 | 填空 | 解答
  topic: '换元积分法',
  year: null,               // 真题填年份数字，否则 null
  question: '题目正文（支持HTML数学标记）',
  options: null,            // 选择题填 ['A. ...','B. ...','C. ...','D. ...']，否则 null
  answer: '最终答案',
  solution: ['第一步：...', '第二步：...'],
  keyPoints: ['【重点】...', '【易错点】...'],
  summary: '一句话方法总结'
}
```



1. 保存文件，刷新浏览器即可

### 添加新章节



1. 在 `js/data/` 下新建 `ch12.js`，按规范注册到 `window.QB_DATA['12']`

2. 在 `index.html` 中添加 `<script src="js/data/ch12.js"></script>`

3. 在 `js/app.js` 的 `getChapters()` 循环中调整章节数范围

## 常见问题

**Q: 打开页面显示 "题目数据加载中"？**

A: 请确认 `js/data/` 目录下所有 `chXX.js` 文件都存在，且浏览器未拦截本地脚本。

**Q: 数学公式显示不正常？**

A: 请使用现代浏览器（Chrome/Edge/Firefox/Safari），不支持 IE。

**Q: 如何重置所有学习记录？**

A: 进入「学习统计」页面，点击底部「重置所有数据」按钮。

**Q: 题目有错误怎么办？**

A: 可以直接编辑对应 `js/data/chXX.js` 文件中的题目数据，修正后保存刷新即可。欢迎提交修正。
